# Our Table font assets

Unmodified variable TrueType fonts from the official `google/fonts` repository. The associated SIL Open Font License files are preserved alongside them. The application self-hosts these assets through `next/font/local`; no Google font requests or additional packages are required at build time or in the browser.

| Asset                | Official source                                                                               | Git blob SHA-1 verified after download     |
| -------------------- | --------------------------------------------------------------------------------------------- | ------------------------------------------ |
| Fredoka-variable.ttf | [Fredoka](https://github.com/google/fonts/blob/main/ofl/fredoka/Fredoka%5Bwdth%2Cwght%5D.ttf) | `349b6ecef8a358ede29b7bf74a08196be5d71b25` |
| Nunito-variable.ttf  | [Nunito](https://github.com/google/fonts/blob/main/ofl/nunito/Nunito%5Bwght%5D.ttf)           | `2ec1f4b0676c83ef33049db87b311171699e9192` |

Fredoka headings use weights 400–600; Nunito body and controls use 400–800. Full source font character coverage is retained, including extended Latin text.
